## Google Gemini 聊天機器人

--主要架構我是參考[Gemini API 快速入門：來用 Js 做一個線上聊天吧](https://emtech.cc/p/gemini-api)這個網站的教學

--我在加上[註冊功能](https://github.com/Rafu2102/_ws/blob/master/%E6%9C%9F%E4%B8%AD/login.html)之後

--設定成註冊完並且登入之後會跳轉到[聊天機器人](https://github.com/Rafu2102/_ws/blob/master/%E6%9C%9F%E4%B8%AD/chat.html)

--主要是利用ChatGpt做版面的美化和排版以及解釋每個程式碼的作用並且加上註解

--要使用聊天功能要先到[Google AI Studio](https://aistudio.google.com/app/apikey)取得個人專屬的Gemini API金鑰

--從這裡註冊登入就可以開始聊天了!-->[登入以及註冊頁面](https://rafu2102.github.io/_ws/%E6%9C%9F%E4%B8%AD/login.html)
